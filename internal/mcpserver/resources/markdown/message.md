One message in full by id: subject, sender, recipients, time, thread id, `in_reply_to` and the Markdown body.

Reading it is always a peek: it never marks the message read, unlike the `read` tool. Use `read` or `mark` when your unread list should change, and `aim://thread/{thread_id}` for the whole conversation. Ids come from digests, `list`, `search` and `wait` and need no encoding: `aim://message/msg-01jcz6x2k3`. An unknown id is not found. No subscribe.
